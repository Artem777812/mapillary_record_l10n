# Mapillary Record language packs

Public downloadable translations for [Mapillary Record](https://github.com/Artem777812/mapillary_record).

The app ships with Russian, English, and German. Extra languages are listed in `catalog.json` and downloaded as JSON packs.

## Files

- `catalog.json` — list of downloadable languages
- `uk.json` — Ukrainian

Do not add `ru`, `en`, or `de` here; those packs are bundled in the app.
